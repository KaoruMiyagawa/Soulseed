# Soulseed Windows 体验版

## 安装

1. 在 Windows 10 或 11 x64 上双击 `Soulseed_2.9.1-beta.10_x64-setup.exe`。安装器使用当前 Windows 账户。如果缺少 Microsoft Edge WebView2，安装器会联网补装。
2. 安装完成后，从「开始」菜单打开 **Soulseed**。你会进入大肥鱼的生活世界，生活手帐、计划和对话都在同一个窗口中。
3. 此体验版目前使用未签名的安装包，Windows 可能显示 SmartScreen 提示。请通过可信来源取得文件，并核对随包提供的 `SHA256SUMS.txt`。可在 PowerShell 中运行 `Get-FileHash .\Soulseed_2.9.1-beta.10_x64-setup.exe -Algorithm SHA256`，逐字核对 SHA256。

## 配置模型并开始对话

1. 在 Soulseed 窗口右上角点击 **模型设置**。
2. 填写支持 OpenAI Chat Completions 的服务商 API 基础地址（例如服务商给出的 `https://域名/v1`）、准确的模型 ID 和你自己的 API Key。程序会在基础地址后加上 `/chat/completions`。本机模型服务可使用回环 HTTP 地址。
3. 点击 **保存**。Windows 会以当前账户加密配置。保存操作只检查填写格式。
4. 在同一设置窗口查看每日模型请求额度。默认上限为每个 UTC 日 20 次，可调低至 1 次；自主探索默认暂停。首次真人测试建议先设为 3 次，保持自主探索暂停，确认服务商配置后再逐步开启。
5. 点击 **对话 → 新会话**，发送消息并等待回复。同步聊天和异步发送入口已接入。每次请求的输出上限为 1024 tokens。额度包括因澄清或纠正流程额外发出的请求。计费以服务商为准。
6. 如需更换服务或密钥，重新填写三个字段并保存。点击 **清除配置** 可删除本机的模型配置。若要使已经签发的 Key 失效，请到服务商控制台撤销。

生成回复时，配置的服务商会收到必要的对话、相关记忆和人格提示。自主探索需先在模型设置取消总暂停，再在探索页启用。主动联系需在模型设置启用并恢复自主功能，可调整安静时段。开启模型主动联系后，大肥鱼也可从自身保存的心情、活动或兴趣出发发起社交；她可能选择沉默。涉及具体经历、用户记忆或探索发现的表达仍须有对应依据。程序完全退出后自主功能停止。

## 退出、升级和删除数据

- 点击窗口右上角的 × 退出。下次从开始菜单打开即可继续使用。
- 升级时先关闭 Soulseed，再运行更高版本的安装包。安装程序默认保留当前账户的数据和模型配置。需要备份时，在退出后复制下列整个目录。
- 在 Windows「设置 → 应用 → 已安装的应用」中卸载 Soulseed。卸载界面默认保留数据，重装后可以继续使用。勾选「删除应用程序数据」会同时清除本机应用资料。
- 若要手动彻底删除，退出 Soulseed 后，在资源管理器地址栏打开 `%LOCALAPPDATA%\com.soulseed.desktop`，删除这个目录。会话、记忆、生活记录、迁移备份、加密的模型配置和 WebView 本地数据都会随之删除。加密模型配置只能由原 Windows 账户在原电脑上恢复。
