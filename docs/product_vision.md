# Soulseed 产品愿景与决策档案

本文记录已经由产品创建者确认的长期方向，供后续设计与实现时核对。记录愿景不表示相应能力已经交付。具体实现状态以 README、安装说明和有证据的验收记录为准。

## 核心表达

> 让每个人都能创造属于自己的、持续成长的数字个体。
>
> A World for Every Individual.

## 已确认的产品原则

1. Soulseed 是承载不同数字个体的平台。大肥鱼是第一个验证角色，不是平台唯一支持的角色。
2. 数字个体的方向包括稳定的人格内核、长期记忆、独立判断、自主行为和持续成长能力。
3. 角色的人格本质保持稳定。随着相处时间增加，数字个体能够更多了解用户，并逐渐形成独特的关系与互动习惯。
4. 长期方向包括原创角色、自定义角色，以及依据合法资料还原已有作品角色。可能采用人格建模、RAG、微调或蒸馏等方法，具体技术路径尚未决定。
5. 相同角色原型创建出的不同数字个体彼此独立，各自拥有记忆、经历和关系。
6. 创建者可以在产品提供的范围内配置数字个体的自主程度。
7. 多个数字个体未来能够彼此认识、交流并建立关系，也可以在用户没有直接参与时共同探索。
8. Soulseed 的数字世界面向持续发生的故事，而非静态房间。
9. 用户对数字个体记忆的修改权限尚未决定。实现前必须重新确认，不得从本档案推导为既定权限。

## 当前能力与长期愿景

当前软件以大肥鱼为首个本地单用户验证角色，包含聊天、有限长期记忆、模型配置、受预算约束的探索与自主联系等已经实现的部分功能。每项功能的可用状态以当前 Windows 安装说明和验收记录为准。

角色创建与选择、多角色实例管理、角色之间的交流与共同探索、基于合法资料的角色还原流程，以及持续展开的三维数字世界，均属于长期方向。它们不是当前版本已经交付的功能。
