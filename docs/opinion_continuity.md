# 角色观点连续性

大肥鱼可以在讨论里自然地赞同、不同意或保留判断。聊天仍使用原来的模型调用。讨论涉及看法时，模型可在正文之后附加一条内部建议。后端只在话题确实出现在本轮用户消息里，且建议引用了正文里的角色原话时，保存值得延续的判断。内部建议与可见正文分开，格式不完整时仍可保留完整正文。普通问候、临时反应、口味、用户立场和未形成的判断不属于这个记录。

迁移 29 增加一张按角色和话题归属的观点版本表。首次形成可以只保存角色自己的理由，修订必须引用该角色在上一版之后完成的相关生活经历，或已完成探索中引用了成功读取来源的结论。每次修订附带依据的摘要和原始记录 ID。保存和聊天回复使用同一事务，生成期间已有更新时只保存回复，保留较新的观点版本。用户记忆仍通过原有提取、检索和纠错流程管理。核心人格继续由原有角色资料定义。

新会话提到同一话题时，现有表达上下文提供最近版本。共享自主社交可以参考相关观点，自发闲聊也可以参考少量近期观点。观点是主观判断，不能替代事实依据。形成与修订发生在聊天中，探索和生活系统仍照常记录经历，相关信息在后续讨论中供重新判断。

第一轮按话题名的文字匹配来召回，没有语义归并、专用浏览界面或后台批量更新。隔离测试用模拟模型和模拟网页读取验证形成、重启、跨会话、修订依据、存档隔离和主动社交接入。
