# Chat-C3 隔离自动化验收

该脚本仅用于自动化验收，不提供独立用户预览入口。运行前在 `frontend` 目录执行 `npm ci`，然后从项目根目录运行：

```powershell
python backend/scripts/preview_chat_c3.py --test
```

测试会启动临时端口的 testing 后端和前端、临时 SQLite 与 Mock Worker，由 Playwright 执行浏览器验收，结束时关闭它们。临时配对凭据只在进程环境中传递，不打印为用户预览口令。Playwright 默认使用本机 Microsoft Edge。可通过 `CHAT_C3_BROWSER_CHANNEL` 选择其他已安装的 Chromium 渠道，或用 `--artifacts` 指定截图和测试附件目录。前端单元测试和类型检查分别运行 `npm test` 与 `npm run build`。

## 发送与恢复

发送时先持久化本地队列，再显示气泡、清空草稿并恢复焦点。队列按 API 地址、已认证用户、角色和会话隔离，使用 Web Locks 在同一浏览器的标签页间串行确认。刷新后恢复同一个流、序号和消息 ID。队首确认不明时先查 C1 状态，查无保存结果再用原身份重试。重试按钮操作的是这条队列记录。冲突会保留原记录并暂停队列，便于核对。

会话使用服务器序号合并消息，通过 `user_message_id` 关联回复。页面隐藏、切换会话或离开聊天时暂停当前视图的网络循环，回到会话后继续确认并读取。待确认正文暂存在当前站点的本地存储，清除站点数据会失去未确认队列。

聊天页通过健康接口和当前会话的消息读取接口显示 Mock、真实严格预算或停用状态。Mock Worker 仅可在 testing 启用；Development Worker 需经过独立的模型预算历史切换，并限于一个明确会话。关闭或预算门禁未开时服务器拒绝新增异步消息，已有消息仍可读取与核对。会话没有待处理任务时，用户可以显式切换到同步聊天。角色回复的 `failed` 和 `unknown` 由服务器报告，发送重试只处理用户消息的保存确认。
