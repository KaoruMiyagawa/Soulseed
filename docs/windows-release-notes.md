# Soulseed v2.9.1-beta.13 · Windows 私人内测版

探索可以用已保存的生活经历、兴趣和有来源的研究结论提出新问题，保留选题依据、网页证据和结论引用。系统会拦截明显重复的问题，并保留同一主题下的不同问题。

服务重启后，未结束的探索会显示为已中断。点击「重新尝试」会关联原任务并创建新任务，保留原有证据与账本。重试使用当前额度。Windows 手动探索与重试都接入严格预算。

beta.13 已从 beta.12 覆盖安装并校验原有数据。Windows 验收使用隔离数据及本机模拟模型，网页正文由测试替身提供。已验证新题与来源、相似题去重、重启后的显式重试、额度、聊天与观点连续性。Windows 原生通知以注入的测试事件单独验证，自主联系的生成和投递使用隔离自动测试。本次未调用真实模型服务或进行真实网页探索。

大肥鱼可以在讨论中形成自己的看法，在新会话中继续聊，也能根据新经历或有来源的探索结论重新判断。变化会留下历史版本和依据。迁移 29 新增角色观点记录，用户记忆、兴趣和生活习惯沿用原有记录。

大肥鱼会根据多个当地日期的已完成活动形成时段习惯。稳定习惯会略微提高对应活动在该时段被选中的机会，已有计划和近期活动仍参与决策。习惯与兴趣分别进入聊天和自主社交上下文。连续的新记录可以改变习惯，无记录的日期不参与判断。

在 beta.9 的基础上，让大肥鱼通过多次保存的生活经历逐步形成、减弱和调整兴趣。成长趋势继续影响现有生活活动选择，并进入网页与 Windows 共用的聊天和自主社交表达上下文；当前心情、角色兴趣与用户记忆分别处理。没有近期聊天也可基于角色自己的生活状态产生自主社交候选。

网页和 Windows 共用联系决策、预算、审核、去重和原会话投递流程；Windows 在窗口不在前台时使用原生通知。

本版本沿用现有聊天、记忆、生活、探索和模型配置；同步及异步聊天的输出上限保持为 1024 tokens。模型配置由 Windows DPAPI 保护。用户可在模型设置中控制每日额度和自主功能。

主动联系中的具体经历、用户信息和探索事实需要相应依据；自然语言事实识别并非完美，仍可能遗漏或误判。模型服务可能产生费用，以服务商规则为准。

安装包供私人内测，当前未签名。升级前关闭 Soulseed 并备份数据；安装器保留当前 Windows 用户的数据和加密模型配置。卸载时可选择保留数据。运行前核对随包 SHA256。
